# Advanced Inventory Management System

## Project Overview
A comprehensive HTML5, CSS3, and JavaScript-based Inventory Management System with built-in billing, GST calculation, profit tracking, and business compliance features.

## Features

### 📦 Inventory Management
- Add, edit, and delete products
- Real-time stock tracking
- Category-based organization
- Supplier management
- Cost and selling price management

### 💰 Billing & Sales
- Tax invoice generation
- Automatic GST calculation
- Profit calculation
- Customer billing with phone tracking
- Invoice numbering system

### 📊 Reports & Analytics
- Dashboard with key metrics
- Category-wise inventory valuation
- Sales history tracking
- Business summary reports
- Stock status reports

### ✅ Compliance
- Business details management
- GST and tax information
- Official filing links
- License and business ID storage

### 💾 Data Persistence
- Browser localStorage integration
- Automatic data saving
- Activity logging

## Technology Stack
- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript
- localStorage API

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/iampriyanshuraj01-beep/WEB-DESIGN.git
```

2. Navigate to the inventory-system branch:
```bash
git checkout inventory-system
```

3. Open `index.html` in your web browser

## Usage

### Dashboard
- View total products, stock, sales, profit, and GST
- See category-wise inventory valuation
- Check recent activity logs

### Products
- Add new products with cost and selling price
- Set GST rates per product
- Filter by stock status (Available, Low Stock, Out of Stock)
- Edit or delete products

### Billing
- Create customer invoices
- Add multiple products to single invoice
- Auto-calculate GST and profit
- Print tax invoices

### Sales
- View complete sales history
- Track profit and GST per invoice
- Customer and contact information

### Reports
- Stock report with availability status
- Business summary with profit and GST totals

### Compliance
- Store business details (Name, License, GSTIN, PAN)
- Direct links to official tax filing portals
- ITR and GST portal integration
